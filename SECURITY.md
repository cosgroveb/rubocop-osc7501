# Security policy

## Supported versions

I provide security fixes for the latest released version of rubocop-osc7501.
Upgrade before checking whether a problem still occurs. Older releases do not
receive security backports.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/cosgroveb/rubocop-osc7501/security/advisories/new).
Do not disclose vulnerabilities in public issues or pull requests.

Include the affected gem, Ruby, RuboCop and terminal versions, reproduction
steps, and impact. Remove credentials and unrelated private data. I coordinate
fix and disclosure timing with the reporter and cannot guarantee deadlines.

For ordinary bugs, use the [issue tracker](https://github.com/cosgroveb/rubocop-osc7501/issues).
